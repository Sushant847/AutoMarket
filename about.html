About AutoMarket

Buy a used car, book a viewing, or list yours. Dataset, privacy and security on this page.

AutoMarket lets people see used cars, enquire with the owner about condition, and book a viewing. Owners can list a car so buyers follow the same process. Cars are not purchased on this website.

Dataset

Australian vehicle prices (2023), 16,000+ listings. The site uses a sample of about 1,000 cars so it opens from a ZIP. New cars you list are stored in this browser and added to that listing set.

Privacy

  • No server accounts.
  • Your listing and recently visited cars stay in this browser.
  • Booking a viewing opens email. We do not store the buyer’s message on a server.
  • Do not use listing data to harass owners.

Login is a demo account — local browser only. Credentials are not sent to a server.

Security

  • Text from listings is escaped before it is shown.
  • No passwords or API keys are in the project.
  • Open index.html from the ZIP. If hosted later, use HTTPS.

Limits

  • Asking prices are not a valuation.
  • Inspect the car, check PPSR, and meet in a safe place.
  • Payment happens off-site after you agree with the owner.
